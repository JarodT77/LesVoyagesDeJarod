Lancer le projet en local
Prérequis
Avant de commencer, assurez-vous d'avoir les éléments suivants installés sur votre machine :

PHP (version 7.4 ou supérieure)
Un serveur web local (par exemple, XAMPP ou WAMP)
Un navigateur web moderne
Git pour cloner le projet
Instructions

1. Cloner le dépôt GitHub
Clonez le projet depuis le dépôt officiel : 
git clone https://github.com/JarodT77/LesVoyagesDeJarod.git

Accédez au répertoire cloné: 
cd BLOG

2. Configurer l'environnement
Placez les fichiers dans le répertoire racine de votre serveur local :
Par exemple, pour XAMPP, placez-les dans htdocs/Blog

3. Lancer le serveur local
Si vous utilisez PHP en ligne de commande :
Ouvrez un terminal.
Placez-vous dans le répertoire du projet: 
cd /chemin/vers/Blog
Lancer le serveur Php: 
php -S localhost:8000

Si vous utilisez un logiciel comme XAMPP :
Assurez-vous que le serveur Apache est démarré.
Accédez au projet en tapant http://localhost/blog dans votre navigateur.

4. Tester l'application
Ouvrez votre navigateur et accédez à :
http://localhost:8000

ou XAAMP:
http://localhost/blog
